**Training Repository** for the Development Playground (Dev Open-Test / DevTemple)

---

## What is this repo?

This is the official training ground for members of the Development Playground.

Here you will find:

- Beginner to intermediate practical challenges
- Clear rules and submission guidelines
- Opportunities to earn badges and level up

**Stacks we focus on:**  
JavaScript, TypeScript, Python, SQL, HTML, CSS, FSCSS, Automation, and Ethical Security Testing.

## How to participate

1. Read the challenge carefully
2. Write clean, readable code with comments
3. Follow the rules of that challenge
4. Submit by:
   - Opening a Pull Request, **or**
   - Pasting your solution in the WhatsApp group, **or**
   - Sending it privately to the admins

See [CONTRIBUTING.md](./CONTRIBUTING.md) for full details.

---

## Rules (Important)

- Stay ethical. No black-hat activity.
- Do not test unauthorized targets.
- Be respectful and help others learn.
- Explain your solutions. Don’t just drop code.

**BUILD. TEST. SECURE. IMPROVE. REPEAT.**
