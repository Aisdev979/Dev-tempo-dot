# Contributing Guide

Thank you for wanting to contribute and level up with us.

## How to submit a challenge solution

### Option 1: Pull Request (Recommended)

1. Fork this repository
2. Create a new branch: `challenge-002-your-github-handle`
3. Put your solution inside the correct challenge folder  
   Example: `challenges/002-python-basic/your-github-handle.py`
4. Add a short explanation at the top of your file or in a `README.md` inside your folder
5. Open a Pull Request with a clear title  
   Example: `Challenge 002 - Python Basic - @yourhandle`

### Option 2: Group / Private submission

- Paste your code + short explanation in the WhatsApp group
- Or send it privately to an admin

## Code standards

- Write clean and readable code
- Add comments explaining important parts
- Use only the allowed tools/modules for that challenge
- Do not copy-paste without understanding

## What happens after submission?

- Admins will review your solution
- You may receive feedback
- Successful completions earn badges and level progression

## Need help?

Ask questions in the group. We are here to help you learn.

---

**Remember:**  
Don’t just copy code. Understand it.  
Don’t just build. Test it.
