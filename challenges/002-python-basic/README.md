# Challenge 002 – Python Basic

**Level:** Beginner  
**Language:** Python  
**Deadline:** 24 hours from announcement

---

## Task

Write a small Python script that does the following:

1. Asks the user for their **name** and **GitHub handle**
2. Prints a short welcome message
3. Asks them to choose a number between **1 and 10**
4. Generates a random number and tells them if they guessed correctly or not
5. Shows how many attempts they used

---

## Rules

- Use only basic Python (`input`, `print`, `if/else`, loops, `random` module)
- Keep the code clean and readable
- Add comments explaining what each part does
