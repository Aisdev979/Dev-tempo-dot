# Challenge 004 – JavaScript Events Basics

**Level:** 2  
**Language:** JavaScript  
**Deadline:** 48 hours

---

## Task

Create a simple HTML page with JavaScript that:

1. Has a button
2. When the button is clicked, it shows an alert with a message
3. Also changes the text of a paragraph on the page
4. (Bonus) Changes the background color of the page

---

## Rules

- Use basic JavaScript + HTML
- Use `addEventListener` or `onclick`
- Keep the code clean and readable
- Add short comments

---

## How to submit

Create a file named `your-github-handle.html` (or folder with index.html + script)  
and open a Pull Request, or paste your code in the group.

You are leveling up. Ask questions if you need help.

**BUILD. TEST. SECURE. IMPROVE. REPEAT.**
