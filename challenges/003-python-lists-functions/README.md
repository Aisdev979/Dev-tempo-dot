# Challenge 003 – Python Lists & Functions

**Level:** Beginner → Intermediate  
**Language:** Python  
**Deadline:** 48 hours

---

## Task

Write a Python script that does the following:

1. Creates a list of at least 5 numbers (you can hardcode them or ask the user)
2. Writes a function that takes a list and returns the **sum** of all numbers
3. Writes a function that takes a list and returns the **highest** number
4. Writes a function that takes a list and returns the **lowest** number
5. Calls all three functions and prints the results clearly

---

## Rules

- Use only basic Python (lists, functions, loops, `print`, `input` if needed)
- Keep the code clean and readable
- Add comments explaining what each function does
