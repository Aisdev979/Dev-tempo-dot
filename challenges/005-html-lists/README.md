# Challenge 005 – Pure HTML Lists

**Level:** 2–3  
**Language:** HTML only  
**Deadline:** 48 hours

## Task
Create a pure HTML page that contains:

1. An ordered list (`<ol>`) of at least 5 items
2. An unordered list (`<ul>`) of at least 5 items
3. A nested list (a list inside another list)

No CSS or JavaScript allowed. Only pure HTML.

## Submission
Create `your-github-handle.html` inside this folder.
