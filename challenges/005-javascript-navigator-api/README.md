# Challenge 005 – JavaScript Navigator API

**Level:** 2–3  
**Language:** JavaScript + HTML  
**Deadline:** 48 hours

## Task
Create a page that uses the **Navigator API** to display:

1. Browser name / user agent
2. Platform (operating system)
3. Language
4. Whether cookies are enabled
5. Online status (`navigator.onLine`)

Show the information on the page when it loads.

## Submission
Create a folder or single HTML file named with your GitHub handle.
