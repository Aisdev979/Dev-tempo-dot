# Challenge 006 – Python Calculator

**Level:** 2–3  
**Language:** Python  
**Deadline:** 48 hours

## Task

Write a Python script that:

1. Asks the user for the first number
2. Asks the user for the second number
3. Asks the user for an operation (`+`, `-`, `*`, `/`)
4. Performs the calculation
5. Prints the result
6. Handles division by zero properly

## Rules
- Use `if / elif / else`
- Keep the code clean and readable
- Add short comments

## Submission
Create `your-github-handle.py` inside this folder.
