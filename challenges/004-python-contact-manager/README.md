 * Task: Build a command-line Contact Book / Task Manager using Python dictionaries and functions.
 * Requirements:
   * Store contacts/tasks using a dictionary (e.g., name as key, phone/email or status as value).
   * Implement functions to add a entry, view all entries, search for an entry, and delete an entry.
   * Use a loop to keep the program running until the user chooses to exit.
   * Keep code modular, clean, and properly commented.
