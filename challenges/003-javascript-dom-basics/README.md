# Challenge 003 – JavaScript DOM Basics

**Level:** Beginner → Intermediate  
**Language:** JavaScript  
**Deadline:** 48 hours

---

## Task

Create a simple HTML page with JavaScript that does the following:

1. Has a button and a paragraph (or empty div)
2. When the button is clicked, the text of the paragraph changes
3. The new text should include the user’s name (you can use `prompt` or an input field)
4. Bonus: Change the background color or text color when the button is clicked

---

## Rules

- Use only basic JavaScript + HTML (no frameworks)
- Use `document.querySelector` or `getElementById`
- Keep the code clean and readable
- Add comments explaining the important parts

---
