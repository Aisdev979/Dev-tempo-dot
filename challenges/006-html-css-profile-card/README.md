# Challenge 006 – HTML + CSS Profile Card

**Level:** 2–3  
**Language:** HTML + CSS  
**Deadline:** 48 hours

## Task

Create a clean profile card that includes:

- A profile image (placeholder is allowed)
- Name
- Short bio
- At least 3 skill tags

## Rules
- Use Flexbox or basic CSS
- Make it neat and centered
- No JavaScript required

## Submission
Create `your-github-handle.html` (or folder) inside this folder.
