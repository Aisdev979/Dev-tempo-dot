# Challenge 004 – Python Conditionals & Loops

**Level:** 2  
**Language:** Python  
**Deadline:** 48 hours

---

## Task

Write a Python script that:

1. Asks the user to enter a number
2. Checks if the number is **even** or **odd**
3. Prints a message telling the user whether it’s even or odd
4. Then prints all numbers from 1 to that number using a loop

---

## Rules

- Use `if/else` and a loop (`for` or `while`)
- Keep the code clean and readable
- Add short comments
