# Challenge 005 – Python Text Replacement

**Level:** 2–3  
**Language:** Python  
**Deadline:** 48 hours

## Task
Write a Python script that:

1. Takes a sentence from the user
2. Takes a word to replace
3. Takes the new word
4. Replaces all occurrences of the old word with the new word
5. Prints the new sentence

Use the `.replace()` method.

Create `your-github-handle.py` inside this folder.
