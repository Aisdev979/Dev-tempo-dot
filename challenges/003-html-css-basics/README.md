Challenge 003C – HTML & CSS Basics
Task:
Build a clean, responsive single-page Developer Profile Card.
Requirements:
1. HTML Structure:
 * Create a semantic layout (<header>, <main>, <footer>, or <card>).
 * Include your Name, GitHub handle, and a short Bio.
 * Add a section listing your top 3 Skills (e.g., HTML, CSS, JavaScript).
 * Include at least one functional link (e.g., to your GitHub profile).
2. CSS Styling:
 * Center the card on the screen (use Flexbox or Grid).
 * Apply custom styling: background color, card box-shadow, border-radius, and crisp typography.
 * Style the skills into visual badges or tags.
 * Add a subtle hover effect on the card or link buttons.
Rules:
 * Use only pure HTML & CSS (no external frameworks like Tailwind or Bootstrap).
 * Keep the code clean, readable, and properly indented.
 * Add comments explaining your CSS layout choices (e.g., flexbox centering).
File Setup & Submission:
 * Name your file your_github_handle.html (you can embed CSS inside a <style> tag or link a style.css file).
 * Save it under: challenges/003-html-css-basics/
 * Push to your fork and open a Pull Request!
