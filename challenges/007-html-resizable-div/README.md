# Challenge 007 – HTML Resizable Div (Beginner)

**Level:** 1–2  
**Language:** HTML + CSS  
**Deadline:** 48 hours

## Task
Create a box that the user can resize.

### Requirements
- A visible box on the page
- User can resize it (use CSS `resize: both`)
- Set a minimum width and height
- Center the box on the page
- Add some text inside the box

## Example CSS
```css
.box {
  width: 200px;
  height: 150px;
  resize: both;
  overflow: auto;
  min-width: 150px;
  min-height: 100px;
  border: 2px solid #333;
  padding: 10px;
}
```
