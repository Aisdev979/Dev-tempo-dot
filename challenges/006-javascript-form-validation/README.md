# Challenge 006 – JavaScript Form Validation

**Level:** 2–3  
**Language:** JavaScript + HTML  
**Deadline:** 48 hours

## Task

Create a simple form with:

- Name input
- Email input
- Submit button

When the user clicks Submit:

1. Check if any field is empty
2. If empty → show an error message
3. If both fields are filled → show a success message

## Rules
- Use DOM + events
- Keep HTML, CSS, and JS clean
- Add short comments

## Submission
Create a folder or file named with your GitHub handle.
