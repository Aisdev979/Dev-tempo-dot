 * Task: Build a dynamic Interactive Todo / Note App using JavaScript, DOM manipulation, and localStorage.
 * Requirements:
   * An input field and an "Add" button to create items dynamically.
   * Render the items to an unordered list (<ul>) in the DOM with a delete button for each item.
   * Save the items to the browser's localStorage so they don't disappear on page refresh.
   * Organize code cleanly across index.html, style.css, and main.js inside your username folder (challenges/004-javascript-localstorage-app/your_username/).
